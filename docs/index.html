CLI & Batch Mode

Common CLI invocations 
# Launch the desktop app
python -m pixelref

# Open the interactive onboarding board or the sample animals board
python -m pixelref examples/scenes/onboard.pxref
python -m pixelref examples/scenes/animals.pxref

# Run a Python script headlessly without opening a window
python -m pixelref --batch script.py [scene.pxref] [--save out.pxref]

# Open the built-in documentation server/viewer
python -m pixelref docs

# Load an example plugin for a single run
python -m pixelref --trust-plugin-path examples/plugins
