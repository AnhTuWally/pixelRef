① The Files tab sits on the right edge alongside Tools / Outliner / Attribute Editor — the same panel-tab pattern, so it adds no new chrome. It lists recent files (most recent first) with their saved thumbnails. The active file is highlighted in blue; a file with unsaved changes gets an orange border (moodboard_v3 above). Click a file to switch (unsaved-changes prompt applies); the panel hides when not needed, exactly like the other panels.

The orange border appears the moment a file is dirty and clears on save. It is the single source of truth for "needs saving" — no separate dot or icon to learn.
One unambiguous signal: orange border = unsaved changes. It appears the moment a file is edited and clears the moment it is saved, so the Files list always tells you at a glance which open files still need saving.

Two no-drag paths to detach: right-click → Open in New Window (or Ctrl+Shift+O), or drag the file out past the window edge. Either spawns a new top-level window holding that file. Dragging a file from one window's Files list onto another's re-attaches it.

Each window has its own Files panel listing its files. The detached window shows moodboard_v3 with its orange unsaved border intact. Dragging a file from one window's list onto the other's merges them back. Closing the last file in a detached window prompts Close window / Re-attach — no empty shells.
