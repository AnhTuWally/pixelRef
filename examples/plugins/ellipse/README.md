# Ellipses

An example plugin to copy: it adds an **ellipse** node type, the **Ellipse
tool** (`O`, then drag) and an Attribute Editor generated from the node
type's attributes.

From the Script Editor:

```python
pxcmd.ellipse.create(0, 0, 200, 120, fill_color=[80, 160, 255], fill_opacity=0.5)
```

This page is the plugin's `README.md`: pixelRef shows it on the plugin's page
in *Window → Plugins…* and in the Help browser.
